# E-Learning Management System

A robust E-Learning Management System developed to provide a digital platform for students, instructors, and administrators to manage and access educational resources efficiently. The system supports online learning through course management, assessments, progress tracking, and interactive learning tools — creating a centralized hub for modern education.

---

## Features

- **Student, Instructor and Admin Login**: Role-based authentication with separate dashboards for each user type.
- **Course Creation and Management**: Instructors can create, update, and manage courses with ease.
- **Learning Material and Video Content Access**: Students can access study materials, documents, and video content online.
- **Assignment and Quiz Management**: Create, assign, and evaluate assignments and quizzes digitally.
- **Student Progress Tracking**: Monitor individual student performance and learning milestones.
- **Course Enrollment System**: Students can browse and enroll in available courses seamlessly.
- **Performance Evaluation and Reports**: Generate detailed performance reports for students and instructors.
- **Certificate Generation**: Automatically generate certificates upon course completion.
- **Dashboard for Students and Faculty**: Personalized dashboards for quick access to relevant information.
- **Secure Authentication and User Management**: Role-based login with secure data handling and user management.

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/Aayush52-bot/elearning-management-system
   ```

2. Open the project in **Visual Studio**:
   - File → Open → Project/Solution
   - Select the `.sln` file

3. Set up the database:
   - Open **SQL Server Management Studio (SSMS)**
   - Create a new database named `elearning_db`
   - Import the provided `.sql` file from the `/database` folder

4. Configure the connection string:
   - Open `Web.config` or `appsettings.json`
   - Update the connection string with your SQL Server credentials:
   ```xml
   <connectionStrings>
     <add name="DefaultConnection" 
          connectionString="Server=YOUR_SERVER;Database=elearning_db;User Id=YOUR_USER;Password=YOUR_PASSWORD;" 
          providerName="System.Data.SqlClient"/>
   </connectionStrings>
   ```

5. Build and run:
   - Press **Ctrl + F5** in Visual Studio
   - The application will launch in your default browser
